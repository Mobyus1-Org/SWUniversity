# Cards Remaining to Implement

Every card in a real set (SOR, SHD, TWI, JTL, LOF, LAW, SEC, ASH, IBH, TS26) that has mechanical
card text and **zero references anywhere in the engine or UI source**. Promo and token printings
are excluded — they duplicate a base-set card.

**This is a floor, not a ceiling.** A card that IS referenced but only half-wired does not appear
here — leader batch 1 found three leaders whose Action was listed in the registries with no
execution case at all. Treat this as "definitely not started", not "everything that is broken".

Each block below is under Discord's 2000-character limit — paste one block per message.

**Total: 880 cards across 10 sets.**
